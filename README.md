# sametmetemutlu

iOS ve web tarafında kendi uygulamalarımı yazıyorum.

## Seçilen işler

| Proje | Ne işe yarar |
| --- | --- |
| [CarPatt](https://github.com/sametmetemutlu/carlpatt) | Kendi M3U listen ve telefon ekranın, park halindeyken CarPlay ekranında. |
| [Fiyat Gurusu](https://fiyat-gurusu-thgn.vercel.app) | Piyasa fiyatını tahmin etme oyunu. Tek oyunculu ve çok oyunculu turlar. [Kaynak](https://github.com/sametmetemutlu/fiyat-gurusu) |
| [Hürkan Alabalık](https://h-rkanlaabal-k-1.vercel.app) | Restoran, canlı balık satışı ve çiftlik için tek sayfalık tanıtım sitesi. [Kaynak](https://github.com/sametmetemutlu/hurkan-alabalik) |
| [Akgül soyağacı](https://akgul-soyagaci-goruntule.vercel.app) | Etkileşimli soyağacı. Kişi eklenir, PNG olarak indirilir. [Kaynak](https://github.com/sametmetemutlu/akgul-soyagaci-goruntule) |
| [Glyphly](https://github.com/sametmetemutlu/glyphly) | Çizdiğin gliflerle yazı tipi oluşturan iOS uygulaması. Çizimler cihazda kalır. |
| [Oyun Kutusu verisi](https://github.com/sametmetemutlu/partygames-data) | Oyun Kutusu için film listeleri ve tahmin soruları. |
